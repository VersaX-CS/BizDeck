✅ FEATURES SUMMARY

Export Everything:
───────────────────────────────────────────────────────────────────────────────
• Creates single JSON file (.bizdeck)
• Includes: credentials, all data, clients, orders, settings
• Filename: bizdeck-account-[email]-[date].bizdeck
• Import: Yes, full restoration

Share:
───────────────────────────────────────────────────────────────────────────────
• Uses native OS share sheet (like invoice sharing)
• Works on mobile to upload directly to Google Drive/email/etc
• Falls back to download on desktop
• Same file as export

Quick Exports:
───────────────────────────────────────────────────────────────────────────────
• Data only (JSON) - no credentials
• Clients (CSV) - spreadsheet format
• Records (CSV) - spreadsheet format

Import:
───────────────────────────────────────────────────────────────────────────────
• Accept .bizdeck files (JSON with credentials)
• Accept .json files (data only)
• Restore everything or just data

Account Credentials:
───────────────────────────────────────────────────────────────────────────────
• Show/Hide: Toggle visibility of key/password
• Copy: Copy to clipboard (with toast confirmation)
• Download: Save to .txt file with security notes

License Document:
───────────────────────────────────────────────────────────────────────────────
• Download license: Creates formatted .txt file
  - All account information
  - Full credentials
  - 6 sections of security guidance
  - Filename: bizdeck-license-[email]-[date].txt

• View details: Opens beautiful modal showing:
  - Account information
  - Access key (with copy)
  - Password (masked, with copy)
  - License status
  - Security reminders

Backup Section:
───────────────────────────────────────────────────────────────────────────────
• Everything consolidated in one card
• Export, Share, Import all visible
• Quick exports grouped together
• Automatic backup settings
• Cloud backup integration
