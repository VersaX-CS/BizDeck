## 🔑 Key Concepts Quick Reference

### Access Key
- 24-character unique identifier
- Tied to email + password
- Used for device transfer
- Generated automatically on signup
- Hidden by default in UI
- See: SECURITY_FEATURES.md → "Access Key System"

### Export Account Backup
- Downloads `.bizhub` file
- Includes all data + credentials
- User keeps the file
- Used for device transfer
- See: SECURITY_FEATURES.md → "Export Account Backup"

### Import Account
- Restores from `.bizhub` file
- Asks for email + password
- Email is locked (read-only)
- Verifies credentials with hash
- Restores all data
- See: SECURITY_FEATURES.md → "Import Account on New Device"

### License Object
- Contains: email, keyHash, accessKey, created
- Embedded in backup file
- Used for verification on import
- See: DEVELOPER_API_REFERENCE.md → "createLicense()"

### Hash (One-way)
- simpleHash(email + password)
- Non-reversible function
- Used for credential verification
- Same input = same hash
- See: DEVELOPER_GUIDE.md → "Security Model"

### Toast Notification
- Temporary notification popup
- Auto-dismisses after 3 seconds
- Success (green), Error (red), Info (blue)
- Used for feedback
- See: UI_UX_REFERENCE.md → "Toast Notifications"
