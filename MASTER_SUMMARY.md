## 🔒 Security Implemented

### What's Secure
- ✅ Passwords never stored in backups (only hashes)
- ✅ Email-based account binding
- ✅ One-way hash verification
- ✅ Local-only operations (no external servers)
- ✅ User controls all backup files
- ✅ Clear policy on responsibilities

### What's Not Encrypted (By Design)
- ❌ Backup files are plain JSON
- ❌ localStorage is plaintext
- ⚠️ User responsibility to secure backup files
- ℹ️ Suitable for local-app without backend

### Security Model Explanation
```
Email + Password → Create Hash → Store Hash
                      ↓
              On Import: Verify Hash
                      ↓
              Match = Restore Account
```
